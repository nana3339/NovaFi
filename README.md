# NovaFi

NovaFi is a lightweight DeFi and open finance smart contract project built on OPN Testnet.

## Overview

NovaFi explores decentralized financial interaction through EVM-compatible smart contracts.

## Features

* Smart contract deployment
* Open finance experimentation
* On-chain interaction
* EVM-compatible architecture

## Technology Stack

* Solidity
* Remix IDE
* MetaMask
* OPN Testnet

## Deployment

Successfully compiled and deployed on OPN Testnet.

## Future Plans

* Decentralized finance utilities
* Tokenized applications
* Financial infrastructure
